The Rundown: In this tutorial, you will learn how to transform campaign data into localized 
content and track your global marketing efforts using Canva’s AI-powered sheets and analytics tools.

Step-by-step:

1. Prepare a CSV with Market, Product Name, Target Audience, and Language Code columns, then in 
   Canva create a new Sheet and import your data 
2. Create a new “Headlines” column, select empty cells, go to Actions, and **click "Fill Empty 
   Cells" to auto-generate localized headlines for each market** 
3. Add a “Campaign Status” column and use Actions to add a dropdown with different status options 
4. Use “Magic Insights” to get AI-powered analysis on anything you want from your spreadsheet
